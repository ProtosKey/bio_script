# Основная идея

Скрипт `bio-script` опрашивает GitHub API за проектами из портфолио и генерирует JSON, который отдаёт для дальнейшего использования.

## Как это работает

1. Обходит репозитории пользователя.
2. В результирующий `project.json` попадают только те, у кого в корне есть валидный `project.yaml`.
3. Сравнивает хэш последнего коммита с сохранённым с прошлого запуска — если не изменился, пропускает репозиторий.
4. Для изменившихся обновляет статистику: звёзды, дата последнего коммита, количество коммитов, язык.

## Конфигурационный файл репозитория

В `project.yaml` есть обязательные поля:

- `category` — категория проекта: мобильная разработка, фронтенд итд.
- `status` — статус проекта: завершён, разрабатывается итд.
- `name` — имя проекта.

А также можно добавлять любые свои поля (токены) — любой ключ верхнего уровня в `project.yaml` попадёт как есть в итоговый `project.json`. `description`, `stack`, `overview` в примере ниже — это и есть такие токены, фиксированного набора для них нет.

Пример:

```yaml
category: mobile
status: active
name: nodal

description: >
  Кроссплатформенное приложение для Android и iOS, которое считает и
  визуализирует полиномиальную интерполяцию по таблице точек.

stack:
  - Compose Multiplatform
  - Voyager
  - Koin

overview: |
  ## Возможности

  - Реализовано семь методов интерполяции.
  - Архитектура разложена по слоям domain / presentation / di.
```

## Настройка

Сначала в `.env` обязательно нужно будет вписать свой GitHub токен.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```
